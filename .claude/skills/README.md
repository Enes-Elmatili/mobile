# Compétences du projet

Chargées automatiquement par Claude Code quand la tâche s'y prête (leur
`description` dit quand). Les règles maison de FIXED restent dans
`CLAUDE.md` et priment en cas de désaccord.

| Compétence | Inspirée de | Sert pour |
|---|---|---|
| `clean-code/` | *Clean Code*, Robert C. Martin | nommage, fonctions courtes, erreurs, tests au quotidien |
| `refactoring/` | *Refactoring*, Martin Fowler | découper sans changer le comportement, tests d'abord |
| `release-it/` | *Release It!*, Michael T. Nygard | production : sockets, reprises réseau, délais, file hors ligne |

Origine : [ciembor/agent-rules-books](https://github.com/ciembor/agent-rules-books)

d'origine plutôt que les modifier ici.
